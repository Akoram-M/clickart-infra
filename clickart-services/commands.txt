docker commands
---------------
1.open mongodb in terminal
docker exec -it clickart-mongodb-1 mongosh -u test -p test --authenticationDatabase admin

2. open postgresql database in terminal 
docker exec -it clickart-postgres-1 psql -U test -d orders_db

open postgresql inventory database in terminal
docker exec -it clickart-postgres-1 psql -U test -d inventory_db

3.Destroy the containers and their attached volumes:
docker compose down -v

4.Purge any lingering orphaned volumes from your Mac just to be safe:
docker volume prune -f

5.Rebuild the architecture from scratch:
docker compose up -d

6.Ensure your infrastructure containers are powered on:
docker compose start

7.Power OFF docker containers:
docker compose stop

8.Reboot the network
docker compose up -d --force-recreate

9.see logs based on the service or container 
docker logs -f clickart-api-gateway
docker logs -f clickart-product-service
docker logs -f clickart-order-service
docker logs -f clickart-inventory-service

10.restart single service or container
docker compose restart api-gateway

11.build docekr iamges
# In config-server directory:
docker build -t clickart/config-server:1.0 .

# In discovery-server directory:
docker build -t clickart/discovery-server:1.0 .

# In api-gateway directory:
docker build -t clickart/api-gateway:1.0 .

# In product-service directory:
docker build -t clickart/product-service:1.0 .

# In inventory-service directory:
docker build -t clickart/inventory-service:1.0 .

# In order-service directory:
docker build -t clickart/order-service:1.0 .

12, targeted deploy
docker compose up -d --no-deps api-gateway
