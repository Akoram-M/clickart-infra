docker commands
---------------
1.open mongodb in terminal
docker exec -it clickart-mongodb-1 mongosh -u test -p test --authenticationDatabase admin

2. open postgresql database in terminal 
docker exec -it clickart-postgres-1 psql -U test -d orders_db

3.Destroy the containers and their attached volumes:
docker compose down -v

4.Purge any lingering orphaned volumes from your Mac just to be safe:
docker volume prune -f

5.Rebuild the architecture from scratch:
docker compose up -d

6.Down docker container and remove 
docker compose down -v

7.Ensure your infrastructure containers are powered on:
docker compose start

7.Power OFF docker containers:
docker compose stop
