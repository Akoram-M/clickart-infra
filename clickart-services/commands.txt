1.open mongodb in terminal

docker exec -it clickart-postgres-1 psql -U test -d inventory_db

3.Destroy the containers and their attached volumes:
docker compose down -v

4.Purge any lingering orphaned volumes from your Mac just to be safe:
docker volume prune -f

5.Rebuild the architecture from scratch:
docker compose up -d

6.Ensure your infrastructure containers are powered on:
docker compose start

7.Power OFF docker containers:
docker compose stop

8.Reboot the network
docker compose up -d --force-recreate
docker compose up -d --force-recreate notification-service

9.see logs based on the service or container

docker logs -f clickart-order-service

k8s
**********
1.Run this command to expose your current configuration state and list all known clusters:
kubectl config get-contexts

2.Run this command to switch the active context:
kubectl config use-context docker-desktop

3.Verify the connection successfully hits the API server:
kubectl get nodes

4.Apply the namespace:
kubectl apply -f k8s/namespace.yaml

5.Apply the Redis deployment:
kubectl apply -f k8s/redis.yaml

6.Verify the Pod is running and physically allocating memory:
kubectl get pods -n clickart

7.Apply the PostgreSQL manifest:
kubectl apply -f k8s/postgres.yaml

8.Apply the Kafka manifest:
kubectl apply -f k8s/kafka.yaml

## single commadn to apply all
kubectl apply -f k8s/namespace.yaml && kubectl apply -f k8s/infra/ -n clickart && sleep 20 && kubectl apply -f k8s/services/ -n clickart && kubectl apply -f k8s/ingress.yaml -n clickart

9.Watch the cluster actively provision the containers. 
Run this command until all three pods (Redis, Postgres, Kafka) show a status of Running:
kubectl get pods -n clickart -w

10.To clean up the stuck pods instantly, forcefully delete the deployment and let Kubernetes recreate it from scratch:
kubectl delete deployment kafka -n clickart

11.Verify the configuration actually changed:
kubectl describe pod -l app=kafka -n clickart | grep Image:

12.Execute this exact command to extract the logs from the last crashed instance:
kubectl logs deployment/discovery-server -n clickart --previous

13.Execute this exact port-forwarding command to bridge your Mac's port 8081 to Keycloak's internal port 8080:

API Gateway (The Entry Point):
kubectl port-forward svc/clickart-api-gateway 8083:8083 -n clickart

Keycloak (The Identity Provider):
kubectl port-forward svc/clickart-keycloak-1 8081:8080 -n clickart

Zipkin (Distributed Tracing):   
kubectl port-forward svc/clickart-zipkin 9411:9411 -n clickart

Eureka (Service Registry):
kubectl port-forward svc/clickart-discovery-server 8761:8761 -n clickart

14.Restart api-gateway 
kubectl delete pod -l app=api-gateway -n clickart

15.check logs
kubectl logs -l app=api-gateway -n clickart -f


Step 1: Install an NGINX Ingress Controller
1.Install Helm
brew install helm

2.Add the NGINX Ingress Repository:
helm repo add ingress-nginx https://kubernetes.github.io/ingress-nginx
helm repo update

3.Install the Controller:
helm install ingress-nginx ingress-nginx/ingress-nginx \
  --namespace ingress-nginx \
  --create-namespace \
  --set controller.service.type=LoadBalancer

4.Verification
kubectl get pods -n ingress-nginx -w

5.Confirm that Docker Desktop has successfully bound the ports to your Mac:
kubectl get svc ingress-nginx-controller -n ingress-nginx

6. install loki
helm repo add grafana https://grafana.github.io/helm-charts
helm repo update
helm install loki grafana/loki-stack --namespace monitoring

Step 2: Deploying the Kube-Prometheus-Stack.

1.Add the Prometheus Community Repository:
helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
helm repo update

2.Deploy the Stack:
helm install monitoring prometheus-community/kube-prometheus-stack \
  --namespace monitoring \
  --create-namespace

3.Monitor the Initialization:
kubectl get pods -n monitoring -w

4.verification : Expose Grafana:
kubectl port-forward svc/monitoring-grafana 8080:80 -n monitoring
